# 研究记录

`tail/full/` 是固定协议的正式机制诊断：计算版本 `769e5ff`，根种子 `20261007`，每格 5000 轮。计算输出由 `metadata.json` 的哈希保护；图表与 HTML 从这些输出派生，单独记录在 `presentation.json`。改进展示不意味着重新运行正式评价。

`tail/quick/` 是种子 `20261006` 的早期流程检查，每格 64 轮，运行于汇总累加顺序修正之前。它不能支持研究结论，不能以其误报率代替正式结果。最终计算版本的一键流程另经检查，记录见 `verification/tail-final-smoke.json`。

`development/quick-seed20261005/` 保存更早的开发流程检查及其源码快照，协议已被替代。保留这些文件是为了说明开发过程；它们未参与正式评价。

`verification/` 保存作者 R 函数的运行来源和数值对照、逐轮结果的独立重算、机制恒等式检查、本地 wheel 检查和报告排版检查。核验范围写在各记录的 `scope` 字段中；数值核验不代替定理证明。

本轮的[结果解读](../../docs/tail-results.md)、[机制推导](../../docs/tail-mechanism.md)与[已知参数候选规模充分界](../../docs/oracle-selection-bound.md)分别说明实验发现与理论范围。v0.2.0 的原始实验仍保留在其他结果目录。
