# 完整重放改善了什么，还没有解决什么

研究记录，2026-10-03。本轮在评价前冻结 [协议](../experiments/parametric-replay-protocol.json) 和计算版本 `d898d36`，使用全新随机流。它承接[补尾机制实验](tail-results.md)，不替换旧数据，也不是 v0.2.0 公共接口的发布验证。

核心结果是：完整重放随机分母能明显改善部分有限样本场景；单纯代入拟合的生成参数仍不能覆盖强持久性或时间模型错配。更高的名义检出率往往伴随更高误报。独立尺寸匹配之后，还能看到有限 Monte Carlo 分辨率带来的功效损失。

## 1. 计算对象与证据

统计量始终检验原始候选的均值，采用逐列拟合的有限目标补尾与 Bartlett HAC 后取最大值。没有去掉共同因子再改检验残差均值。

生成器拟合两个参数：逐列中心化 `gamma1/gamma0` 的平均作为共同 φ，中心化 Pearson 平均相关投影到 `[0,1]` 作为 ρ。完整重放每次重算逐列 φ、HAC、补尾因子与胜出候选。ρ 不进入统计量，因此没有在内层无意义地再次拟合 ρ。

正式计算包含 13,000 份外层数据、每份 199 次内层模拟，共保存 147,000 条方法记录。信号 δ=1、2、3 共用同一轮噪声，不能当成三倍独立样本。尺寸校准、零均值评价、功效评价使用独立阶段与种子。

- [三张图与完整报告](../results/research/replay/full/report.html)：全部格点、方法定义及下载文件。
- [逐方法汇总](../results/research/replay/full/summary.csv)、[配对差异](../results/research/replay/full/paired.csv)：点态区间、拒绝不一致计数与选择结果。
- [原始运行](../results/research/replay/full/metadata.json)、[独立审计](../results/research/replay/full/audit.json)：源码与输出哈希、147,000 条记录的 p 值/拒绝/摘要一致性检查；另将 33 个快照样本按不同内层批次完整再生成。最大归一化数值差为 `1.055×10⁻¹⁵`。

计算约 12.7 分钟。没有因拟合或尺度失效删掉数据，也没有按拒绝率修改规则。报告生成仅读取哈希核验后的数据；PNG、SVG 和 PDF 可单独重建。

## 2. 名义 5% 下的零均值结果

表中 Gaussian 使用同一补尾统计量及拟合相关临界值；“真实 DGP”是知道生成参数的重放参照；“完整拟合”生成时两个参数都由数据估计；“冻结因子”重算 HAC，但冻结原样本逐列补尾乘数。

| 格点 | T / K / φ / ρ | Gaussian | 真实 DGP 重放 | 完整拟合重放 | 冻结因子 |
| --- | --- | ---: | ---: | ---: | ---: |
| G1 | 128 / 20 / 0 / 0 | 9.3% | 5.1% | 5.2% | 5.7% |
| G2 | 200 / 1 / .99 / 0 | 25.4% | 5.5% | 16.6% | 21.3% |
| G3 | 512 / 20 / .90 / 0 | 16.1% | 6.6% | 7.3% | 11.7% |
| G4 | 512 / 20 / .90 / .35 | 11.8% | 4.3% | 4.8% | 7.2% |
| G5 | 512 / 100 / .90 / .35 | 19.4% | 5.3% | 6.4% | 12.2% |
| G6 | 1024 / 20 / .96875 / .35 | 18.9% | 6.0% | 7.4% | 12.6% |
| G7 | 512 / 20 / 异质时间参数 / .35 | 31.4% | 5.6% | 30.0% | 30.3% |

每格 1,000 个独立外层重复，完整点态 95% Wilson 区间在报告中。三个重点格点的完整拟合区间分别为：G2 **14.42%–19.03%**，G5 **5.04%–8.09%**，G7 **27.24%–32.91%**。

在 G5，完整拟合相对 Gaussian 的配对拒绝率差为 **−13.0 个百分点**，配对正态近似区间为 **−15.09 至 −10.91 个百分点**；相对冻结因子为 **−5.8 个百分点**，区间 **−7.25 至 −4.35 个百分点**。这些是指定格点的描述性比较，没有进行全体方法/格点的多重比较调整。区间重叠不能替代配对分析。

预设检查要求六个正确模型格点各自的单侧 Clopper–Pearson 上界不超过 7%，每格错误概率 `0.05/6`。只有 G4 通过。G1 的点估计为 5.2%，但上界为 7.13%；这表示本轮样本量未建立预定容差，不能改写成“已证明真实误报大于 7%”。G2 的明显失准则不能用 Monte Carlo 精度解释。

真实 DGP 的有限样本保证来自交换性，见[证明](parametric-replay.md)，不来自表中每个估计值刚好等于 5%。G3 的 6.6% 点态区间不含 5%；其零均值精确 rank 原理与数值实现均单独核验。多个点态区间不能按同时覆盖解释，不能仅凭这一点反推定理无效或算法正确。

## 3. 拟合的时间结构是怎样进入误差的

G2 中 `T(1−φ)=2`，不是前面渐近证明要求趋于无穷的有效信息区域。估计缺口比 `(1−φ̂_common)/(1−φ)` 的样本中位数为 **3.77**。φ̂ 看起来仍接近 1，但其离 1 的距离已经大幅改变了模拟的持久性。

该格点仅拟合时间参数的拒绝率与完整拟合都为 16.6%；相关参数不存在独立信息。真实 DGP 重放为 5.5%。因此不能把这一残差解释成“需要再估一个相关矩阵”。[方法说明第 8 节](parametric-replay.md)证明了具体 φ 估计器的非退化 local-unit 极限及补尾统计量的随机路径极限；尚未证明整个 fitted bootstrap 的该区域拒绝率极限。

G7 的共同因子 φ=.98、个体成分 φ=.30。瞬时相关为 .35，而真实样本均值的相关为 **.96291**。平均 Pearson 相关估计即使拟合瞬时结构，也不能替代均值相关。

此格点只拟合时间参数为 30.3%，保留真实时间参数而只拟合相关为 6.7%，完整拟合为 30.0%。在这个预设生成器内，时间结构错配是明显的主要误差来源；它不证明任意模型里相关估计都不重要。G7 没有一个正确的共同时间 φ，所以已知共同 φ 的 GLS 参照明确省略。

## 4. 功效需要在相近实际尺寸下比较

G4 和 G7 各额外 2,000 轮零均值数据，为每个方法校准分数阈值，随后独立评价。阈值选第 1901 个次序统计量；跨校准平均尺寸为 `100/2001=4.9975%`，一次校准的条件尺寸服从 `Beta(100,1901)`，95% 分布范围为 **4.09%–5.99%**。这是真实 DGP 已知的模拟比较手段，不是可直接交给数据使用者的校准方法。

G4 独立校准后的零均值频率为：Gaussian、真实 DGP、完整拟合均 4.0%，冻结因子 4.5%，GLS 5.2%。G7 对应为 5.3%、5.1%、4.7%、4.7%。有限评价频率的区间另存，不能把一次校准的条件尺寸当作恰好已知的 5%。

δ=3 表示只有第 0 列的均值为其真实有限 T 均值标准误的三倍：

| 方法 | G4 名义检出 | G4 尺寸匹配 | G7 名义检出 | G7 尺寸匹配 |
| --- | ---: | ---: | ---: | ---: |
| Gaussian 拟合相关 | 66.5% | 44.4% | 98.3% | 79.2% |
| 真实 DGP 重放 | 45.9% | 44.4% | 79.6% | 78.8% |
| 完整拟合重放 | 47.0% | 44.7% | 98.1% | 23.3% |
| 冻结因子 | 56.4% | 44.2% | 98.1% | 22.5% |
| 已知 φ 的 GLS | 58.2% | 60.2% | 不适用 | 不适用 |

G4 完整拟合相对真实 DGP 的尺寸匹配差为 **0.3 个百分点**，配对区间 **−0.51 至 1.11 个百分点**。没有证据把 44.7% 和 44.4% 描述成已建立的功效改进。已知 φ 的 GLS 改变了均值估计器并使用不可获得的真实时间参数；其更高功效是一个参照，不能转移给未知 φ 版本。

“拒绝且选中信号列”的联合频率另存：G4 完整拟合在 δ=3 尺寸匹配后为 43.1%，低于全局拒绝的 44.7%。这不是对所选列的单独显著性保证。

## 5. G7 的尺寸匹配损失还包含 Monte Carlo 分辨率

本轮固定 `B=199`，rank p 的最小值为 .005。G7 完整拟合在零均值校准中已有 **22.0%** 的 p 值达到最小值；δ=3 时为 **96.1%**。校准分数为 `1−p+U/200`，其中 U 独立均匀。大量同值使尺寸匹配阈值 `.99892215` 落入最后一个扰动区间。

在该固定阈值下，任何信号的条件匹配功效都不超过 `200(1−.99892215)=21.56%`；这是[分数上限的直接证明](parametric-replay.md)，约束的是预设的扰动分数比较。δ=3 的观测频率 23.3%，区间 20.79%–26.02%，与这个期望上限并不矛盾。

因此不能把功效从 98.1% 降到 23.3% 全部归因于随机 HAC 或信号不可识别。它同时反映错误生成模型造成的极端 p 值、固定 B 的分辨率，以及独立扰动打破同值的比较规则。同一个原样本统计量直接用连续 Gaussian 分数校准，在 G7 得到 79.2%，也说明底层最大值本身并没有同样的 21.56% 上限。

增加 B 或改用连续比较分数可能减轻这一瓶颈，但本轮没有据结果改 B，也没有把改后的规则混进正式表格。任何后续改法须另立协议、用新评价随机流检验；增加 B 也不会自动修复未知参数下的名义尺寸。

## 6. 当前成果的定位

参数 bootstrap、Monte Carlo 秩检验和 nuisance confidence set 都是已有方法。本轮增加的是可核查的具体条件、时间拟合误差与随机分母的分解、local-unit 路径结果，以及独立尺寸/功效评价；这些并不自动建立方法原创性。

下一步真正需要解决的是未知参数的不确定性，而非只继续把估计点模拟得更精确。已有 Berger–Boos/Dufour 路线要求参数集合覆盖真实值，并对连续参数给出可证上界。有限网格最大值只是真正 supremum 的下界，不能包装成有限样本有效检验。近期文献及本项目尚未完成的构造见[研究方案](research-plan.md)和[证明说明](parametric-replay.md)。

这一阶段没有把拟合重放接入 `audit_returns`，没有更新线上版本。保留失败结果比给尚未覆盖边界的方法加上“可靠”标签更有研究价值。
