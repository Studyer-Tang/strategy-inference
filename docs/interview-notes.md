# 项目说明与讨论提纲

项目研究时间依赖与固定候选筛选如何改变均值显著性。说明以实际算法、冻结配置和正式结果为准；试跑用于开发，确认实验用于评价。v0.1 基线与 v0.2 独立确认的数值分别保留在[结果解读](results.md)。

## 简短介绍

这个 Python 包检查同一段历史上比较多项策略后的均值证据。输入是同期候选策略相对基准的每期净收益差分；输出包括单列 Student、HAC、全族 stationary-bootstrap max 推断和同时区间。各列共享重抽样索引，以保留共同市场冲击。

在独立确认实验的一组 50 候选设置中，未经筛选调整的 HAC 误报率为 71.35%，固定尺度全族检验为 10.65%，逐轮 HAC 为 6.10%（95% 点态 Monte Carlo 区间 5.13%–7.24%）。重新学生化降低了本轮观察比例，仍没有证明名义 5% 的有限样本控制。项目保留这种改善与残余偏差，而不把实现一个方法写成已经解决了校准。

完整确认已经完成：19 个预设零均值格点仅 1 个满足工程上界门槛。$T=2048,\phi=0.9$ 的强持久性 holdout 误报率仍为 10.60%（8.84%–12.66%）。这一负结果限定了当前方法的使用范围，也保留了需要继续研究的问题。

## 展开介绍

量化研究里有两个不同问题：收益依赖改变均值估计误差，标准误按独立样本计算可能偏小；在同一份数据上试很多策略，随后把胜出者当成事前指定策略检验，会引入筛选效应。前者需要处理时间依赖，后者需要把固定候选族一起纳入推断。

项目先用 AR(1) 的长程方差解释独立检验，再固定依赖强度扩大候选族，最后用高斯 AR、重尾成分 AR 和 GARCH 比较零均值误报与植入信号的检出能力。v0.1 保留固定原样本 HAC 分母；v0.2 增加逐轮重估 HAC、stationary-bootstrap 条件方差解析诊断和已知高斯协方差参考。

两个 bootstrap 方法共享数据和索引，正式确认使用区别于开发试跑的种子与冻结协议。保存的 CSV 提供边际拒绝次数与区间，没有保存逐次联合拒绝指标，所以对外不宣称已经进行了配对差异检验，也不把同一名义水平的原始功效当作匹配实际误报率后的功效。

## 简历中的写法

**Strategy Inference｜金融策略均值的时序与筛选调整**

- 实现 Bartlett HAC、共享时间索引的 stationary-bootstrap 最大统计量检验及同时区间，支持固定与逐轮重估尺度，明确固定候选族和单侧均值目标。
- 推导并核对 stationary-bootstrap 均值的精确条件方差，加入已知协方差的高斯模型参考，用于区分尺度估计与重抽样近似。
- 构建事前冻结的开发基线与独立确认实验，保留原始计数、点态 Monte Carlo 区间、同时工程判据和未通过名义水平的格点；说明假设与失败边界。

性能数字需同时给出数据过程、样本长度、候选数及复现记录。“首次”“机构级”“已实现通用显著性控制”均没有当前证据支持。后续若有样本外案例或新理论，再补充相应可验证结果。

## 常见追问

### 1. 为什么先检验均值，而不直接审计 Sharpe ratio？

均值让时间依赖与搜索效应容易分离，AR(1) 场景也有可核对的长程方差。Sharpe ratio 同时估计均值和波动率，是另一个函数参数，需要重新定义标准误和重抽样统计量。当前先完成一个边界明确的推断问题。

### 2. HAC 解决了什么，还剩什么？

HAC 估计均值误差的长程方差，适当条件下处理自相关和异方差。它不自动处理筛选，也不能修复成本错误、数据泄漏或结构突变。本轮 50 候选设置中，胜出者 HAC 误报比例为 71.35%，说明单列依赖调整与全族调整承担不同任务。

### 3. AR(1) 的推导能口头说明吗？

边际方差为 $\sigma^2$ 时，自协方差为 $\sigma^2\phi^{|h|}$。长程方差是零阶方差加两倍正滞后自协方差之和；对几何级数求和得到 $\sigma^2(1+\phi)/(1-\phi)$。$\phi=0.5$ 时，均值标准误在大样本中约为独立公式的 $\sqrt3$ 倍。有限样本均值方差还带有 $1-h/T$ 权重。

### 4. 为什么所有列必须一起重抽样？

候选常暴露于同一市场冲击，全族最大值分布受列间相关性影响。共享行索引保留这种关系；逐列独立重抽样会人为改变横截面相关性。嵌套候选规模也复用同一最大候选集的索引，以保持比较一致。

### 5. 为什么先去掉每列样本均值？

要近似的是零假设下的均值误差分布。直接重抽原数据会把观察到的正均值继续当作信号。全部中心化到零采用族零假设的最不利边界。加入很多明显负均值候选可能使这种边界较保守，但对这一影响的量化需要另外设计。

### 6. 这是 White Reality Check 或 Hansen SPA 吗？

问题设置受完整候选族检验启发，当前算法是 stationary-bootstrap max 检验，支持固定原 HAC 分母与逐轮 HAC 两种版本。Hansen SPA 还涉及数据依赖的零假设修正，本项目没有实现该步骤。介绍时使用具体算法名称，文献说明原方法来源。

### 7. 为什么增加逐轮学生化？

原尺度一致且均值 bootstrap 有效时，固定尺度有一阶渐近依据，但有限样本可能仍有偏差。只有一列时，固定分母在原样本与 bootstrap 比较两边相消，单改原 HAC 带宽不会改变该 p 值。逐轮重估 HAC 将尺度估计的类似随机变化纳入 bootstrap，本轮相关 AR 设置的观察误报比例较低；这仍不是二阶正确性或精确校准的证明。

### 8. 拒绝全族以后，能说胜出策略有效吗？

首先得到的是反对“所有候选均值都非正”的证据，不是未来盈利保证，也不证明胜出者优于其他候选。调整后的列级结果和同时区间能帮助查看各列证据。策略身份识别、均值差比较和条件选择推断需要另外定义目标。

### 9. 为什么同时区间可以筛选后查看？

其目标是所有列均值同时被覆盖；在该联合覆盖事件上，任何根据数据选择的列也被覆盖。这是联合覆盖支持的无条件陈述，不是给定某一项胜出的条件覆盖。当前区间仍依赖渐近近似；单侧最大值和双侧绝对最大值也使用不同临界值。

### 10. Monte Carlo 区间究竟针对什么？

外层 Wilson 区间针对重复模拟的拒绝比例，是每格点的点态区间。内层条件尾概率区间针对给定数据下有限 bootstrap 次数的计算误差。API 的同时区间则针对候选均值。工程验收还使用跨预设格点的同时拒绝率上界，四者不能互换。增加 $B$ 改善计算精度，不会自动修复近似分布偏差。

### 11. 两个方法用了相同随机数，为什么不报告配对显著性？

共享随机数与实际保存配对信息是两回事。比较拒绝率差异需要联合拒绝计数或逐次指示，以估计差值的 Monte Carlo 方差。现有 CSV 只存边际计数，因此能报告 10.65% 与 6.10% 相差 4.55 个百分点，不能据此给出已经算过的配对 p 值。以后需要这种分析时应在新协议中预设并保存信息。

### 12. 重尾和 GARCH 场景检验了什么？

重尾检查大观测的影响，GARCH 将均值自相关与波动聚集分开。创新由单位方差 $t_5$ 的共同和特有成分构造，混合边际并非严格 $t_5$。GARCH 参数满足四阶矩条件；实验没有覆盖无限方差，也不能把需要更高矩的 bootstrap 定理直接套用到本组模拟。

### 13. 为什么不直接换成自动块长？

PPW 选择针对方差估计 MSE，并不直接优化最大值检验误报率。理论 AR 公式在 $T=512$ 时给出 $\phi=0.5$ 约 9.69、$\phi=0.8$ 约 21.63，不总比默认 16 更大。多列还需要预设共同块长的聚合规则。本轮仅改变学生化，使比较能解释，预设敏感性不用于事后替换主参数。

### 14. 为什么增加块长不保证更好？

正自相关下，渐近 leading bias $-G/\ell$ 解释短块重启可能低估均值方差。但它不是有限样本精确校正，也不是检验 size 的单调性定理。解析条件方差包含循环自协方差和有限样本配对权重；不同符号、循环边界、有效块数以及随机分母都会影响结果。应把方差诊断与检验校准分别报告。

### 15. 已知协方差参考有什么用？

高斯 AR 的均值具有已知联合正态分布，可以用真实有限样本均值方差标准化，再用一维积分计算相关最大值的尾部。它核对模拟流程，并提供模型内的拒绝率参照。它使用生成参数，真实数据 API 没有这些真值；不能把它的临界值直接套在随机 HAC 最大统计量上。

### 16. 同样名义 5% 下，功效更高就更好吗？

不能直接这样比较，误报更多的方法也常更容易拒绝。第一列植入三个理论长程均值标准误的信号时，逐轮 HAC 的高斯 AR、重尾成分 AR、GARCH 全族拒绝比例分别为 63.90%、63.65%、63.45%；这是原始同名义水平结果。既不是正确选中信号列的概率，也没有匹配实际零假设 size。公平比较需要独立校准和备择评价。

### 17. 工程验收的 7% 与名义 5% 是什么关系？

名义检验水平仍为 5%。7% 是有限模型基准预设的容忍上限，要求 19 个格点的 Bonferroni 单侧 Clopper–Pearson 上界全部不超过它。某上界超过 7% 表示没有按该标准证成实际误报率不超过 7%，仅凭这个上界不能证明真实值大于 7%。通过也不能推导对所有金融数据有效。

本轮 1 个通过、18 个未过，统计验收失败；程序执行和输出则正常完成。例如负自相关 holdout 的观察比例为 5.00%，同时上界 7.23%，仍未达证据标准，不能将这个未通过直接说成真实误报率超过 7%。强持久性 holdout 的 10.60% 则显示了需要继续处理的实际偏差。

### 18. 完整候选集能解决所有数据挖掘吗？

不能。固定候选族需要完整输入，但完整列集合并不自动覆盖看到结果后持续生成新策略的自适应过程。训练、参数估计、评价期和停止规则都要记录。只提交最终赢家无法还原隐藏搜索，成本与时间定义也不是数组校验能推断的事实。

### 19. 为什么保留负结果，下一步做什么？

研究实现应保存有限样本偏差和失败格点，才能说明方法在哪些条件下有问题。本轮主实验、holdout、敏感性与工程记录均已完成。下一步可分别研究强持久性下的尺度与块近似；改变带宽、块长或目标时，应另立协议、使用新数据流并保留本轮。公开真实数据案例还需要明确时间划分、成本定义和完整候选记录，不能用交易收益图替代推断设计。

## 讨论时应带着的材料

展示主图时，同时打开冻结配置、原始计数和运行元数据。解释一次 AR 长程方差推导、一次共同索引重抽样，再指出一个尚未覆盖的情形。遇到 degenerate resample 或极端浮点尺度时，程序明确失败，不能删去失败轮次后继续报告显著性。

经典方法已有论文和软件实现。本项目目前可验证的工作是清楚的统计范围、透明的计算约定、可复现的独立评价与诚实的失败边界。新的学术贡献需要另行提出并证明。

## 未知参数研究的讨论材料

仅把估计 φ 代入已知参数 t 检验，不能继续声称精确 Student 分布。新协议在 `T=200、φ=.99、K=1` 下观察到代入方法 28.2% 的误报率；这里没有策略筛选，失准来自未知时间参数及其估计。

置信集合检验的有效性来自一次参数覆盖失败事件与每列已知参数 t 尾事件的并集界，所以 β 全族只收取一次。参考列可以有信号，因为形状投影消去常数均值；集合与均值检验也不需要独立。解释这个包含关系，比笼统说“考虑了参数不确定性”更有内容。

代价同样需要展开。在 `T=512、φ=.9、K=20、δ=3` 下，已知参数 5% 检验功效58.9%，同一保守临界值参照57.4%，未知参数认证1.1%。主要损失来自参数集合的最不利检验，不是0.5%的覆盖预算本身。31,000次调用没有认证预算耗尽，但这不意味着数值外包完全没有代价。

还应能解释为什么外包保留1会阻止拒绝、为什么这只给本程序的功效上限、以及怎样另立协议改进形状检验，而不是事后调投影秩挑最好结果。带上完整证明、配对计数和逐轮区间；经典前例与本项目实现之间的关系见[方法说明](parameter-uncertainty.md)。

## 联合参数信息

应能从固定块投影推导两个独立 Wishart 散布矩阵，再逐列用嵌套 Schur 残差解释 Wilks 的独立 Beta 乘积。这说明任意正定列间协方差可以消去，而不需要假设策略独立；当块均值投影秩低于选列数时，仍只需要块内残差矩阵满秩。

接着解释正负矩、负矩存在的严格自由度条件，以及为什么仅依赖自由度挑选幂阶不额外支付多重检验预算。必须说清 Chernoff 界并非精确分位数、多尺度会分摊预算，第一八列上限和奇异回退都可能损失信息。更多信息是否转化为功效，由新冻结数据中的配对差回答；不能把已知参数参照当成实用竞争算法。

这轮可以讨论的研究贡献是模型中已有工具的严格组合、连续参数数值认证及成本分解。不能把 Wilks 分布、Bernstein 外包或共享参数集合说成本项目首创。完整推导见[联合方法](joint-uncertainty.md)，结果与失败情形见[正式记录](joint-results.md)。
