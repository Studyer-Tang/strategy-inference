# 项目说明与讨论提纲

这些说明围绕第一版已经限定的统计问题：时间依赖与固定候选筛选如何影响均值显著性。具体性能数字应引用仓库内保存的实验配置和原始结果，不使用一次试跑的最好数字。

## 简短介绍

我做了一个 Python 包，用来检查同一段历史上比较多项策略后的均值证据。输入是候选策略相对基准的每期净收益差分；输出包括普通单列检验、HAC 检验、共同索引 stationary bootstrap 的全族检验与同时置信区间。实验将时间依赖和策略筛选分开，比较它们对误报率和检出率的影响。

## 展开介绍

量化研究里常见两个不同问题：收益序列有依赖，标准误按独立样本计算偏小；同一份数据上试了很多策略，最后又把胜出者当作事前指定策略检验。前者需要处理均值估计误差中的时间依赖，后者需要把候选族一起纳入推断。

这个项目保留三个可核对层次。先用 AR(1) 的长程方差解释独立检验为什么会产生过多拒绝；再固定依赖强度扩大候选族，观察单列 HAC 调整不能消除筛选效应；最后用正态 AR、重尾 AR 和 GARCH 比较有限样本的校准与检出能力。

实现采用原样本 HAC 标准误作为固定尺度，各列共享 stationary bootstrap 的时间索引。模型、选择规则、块长规则、随机种子和拒绝次数都随结果保存。第一版的工作是把已有统计方法实现清楚并检验有限样本行为，不包含新定理，也没有把模拟结果当作真实交易业绩。

## 简历中的写法

**Strategy Inference｜金融策略均值的时序与筛选调整**

- 实现 Bartlett HAC 标准误、共同索引 stationary bootstrap 的最大统计量检验及双侧同时区间，明确固定候选族、单侧均值目标和渐近适用条件。
- 构建三组可复现实验，分别研究时间依赖、候选规模和重尾／波动聚集下的误报率与检出率；保留配置、原始计数和 Monte Carlo 区间。
- 用公式核对、参考实现比较与边界情况测试验证计算，并将方法假设、筛选规则及局限写入独立说明。

这些表述不需要添加“首次”“领先”“机构级”等形容词。如果后续有真实样本外实验、运行时间比较或新的理论结果，再写入对应的可验证事实。

## 常见追问

### 1. 为什么只检验均值，而不直接审计 Sharpe ratio？

均值让时间依赖与搜索效应的机制容易分离，而且 AR(1) 场景有可核对的长程方差。Sharpe ratio 同时估计均值和波动率，是另一个函数参数，其标准误和重抽样统计量需要重新定义。第一版先把一个对象做好，再扩展到风险调整后的指标。

### 2. HAC 解决了什么，还剩什么？

HAC 估计的是均值误差的长程方差，适当条件下处理自相关和异方差。它不自动处理先筛选再检验，也不能修复数据泄漏、成本估计错误和结构突变。实验中同时使用 HAC 和全族检验，正是为了区分这两种统计影响。

### 3. AR(1) 的推导能口头说明吗？

边际方差为 $\sigma^2$ 时，自协方差为 $\sigma^2\phi^h$。均值的长程方差是零阶方差加两倍正滞后自协方差之和。对几何级数求和，得到 $\sigma^2(1+\phi)/(1-\phi)$。例如 $\phi=0.5$ 时，均值标准误约为独立公式的 $\sqrt3$ 倍。

### 4. 为什么所有列必须一起重抽样？

候选策略常暴露于同一市场冲击。族检验统计量是所有列标准化均值的最大值，其分布受列间相关性影响。共享行索引保留这种关系；逐列独立重抽样会在算法里造出原数据不存在的横截面独立性。

### 5. 为什么要先去掉每列样本均值？

要估计的是零假设下的均值误差分布。直接重抽原数据，会把观察到的正均值继续当成信号。全部中心化到零使用了族零假设的最不利边界，但可能牺牲检出能力，尤其当加入很多明显差的候选时。

### 6. 这是 White Reality Check 或 Hansen SPA 吗？

问题设置受 White 的完整候选族检验启发；本版实现是固定原样本 HAC 尺度的最大统计量 stationary bootstrap。它不是逐轮重新 studentize 的 bootstrap-$t$，也没有实现 Hansen SPA 的数据依赖零假设修正。因此对外使用具体算法名称，不把经典方法名当作泛称。

### 7. 为什么 bootstrap 的标准误不每轮重算？

原尺度一致、均值 bootstrap 有效时，固定尺度已经能得到一阶渐近近似。这样可以简化算法和计算，但不声称高阶精度。特别是只有一列时，原尺度在 bootstrap 比较两边相消，得到的是均值误差 bootstrap 检验。

### 8. 最大统计量检验拒绝以后，能说胜出策略有效吗？

首先能说的是有证据拒绝“所有候选均值都非正”。它不是策略身份识别的保证，也不证明胜出者优于其他候选。同时区间可以帮助查看各列均值的证据；要比较两项策略的均值差、讨论真实获胜概率或条件选择推断，需要额外设计。

### 9. 为什么同时区间可以筛选后查看？

其覆盖目标是所有列同时被覆盖。这个事件发生时，任何根据数据选择出的列也被覆盖。得到的是联合覆盖所支持的无条件陈述，不是给定某一项恰好胜出的条件覆盖。单侧检验和双侧区间使用不同的最大值，不能混用临界值。

### 10. 怎么区分模拟误差和方法本身的偏差？

每个配置重复生成独立数据，报告拒绝次数、比例和 Monte Carlo 区间。内层 bootstrap 尾概率还有抽样误差，外层重复次数与内层 bootstrap 次数分别控制两种误差。观察到一点超过 5%，要结合区间、样本量和预先固定的敏感性实验讨论，不能换种子直到图看起来好。

### 11. 重尾和 GARCH 场景有什么意义？

重尾场景检查偶发大观测的影响；GARCH 场景把均值自相关与波动聚集分开。创新由单位方差 $t_5$ 的共同和特有成分构造，其混合分布并非严格 $t_5$。本次 GARCH 参数满足四阶矩条件，故实验没有覆盖无限方差情况。

### 12. 为什么块长采用固定规则？

块长太短会削弱依赖，太长会减少有效重抽样块数。第一版固定样本量规则，避免根据显著结果反复调参。规则不是最优性的结论；实际研究要报告事前约定的敏感性范围，再考虑可核对的自动选择方法。

### 13. 完整候选集能解决所有数据挖掘吗？

不能。它是固定候选族检验的必要信息，但不普遍处理研究者看到结果后不断创造新策略。训练、参数估计、评价期、停止规则和策略形成过程都需要记录。只提交最后的赢家，更无法从收益曲线恢复隐藏的搜索。

### 14. 项目有什么实际用途？

适合在固定策略比较实验中，把“独立单列结果”“依赖调整结果”和“完整候选族结果”并列呈现，帮助判断证据在哪里改变。它也提供一个能修改参数并重新运行的统计实验基础。其用途取决于输入及评价设计质量，不承担自动判定可交易性的功能。

### 15. 下一步会做什么？

先加入事前规定的块长、带宽和负均值候选敏感性实验，再与成熟软件中的相关检验逐项比较。之后选择一份有明确时间划分、完整试验记录的公开数据做案例。只有当前范围的假设与有限样本表现说清楚以后，再决定是否实现 SPA、策略拟合重抽样或在线推断。

## 讨论时应带着的材料

展示三张图时，同时打开对应配置和原始表格。解释一个 AR(1) 长程方差推导，说明共同索引重抽样如何生成，再指出一个本项目没有处理的情形。这样可以把讨论落到方法、代码和证据上。

如果被问“这些经典方法是否已经有人实现”，答案是有。本项目的价值在于问题范围清楚、计算约定透明、实验可以复现，以及能解释方法的表现与边界；新的学术贡献需要后续另行证明。
