# 第一轮模拟结果

本页对应 `results/full/run-metadata.json` 保存的完整运行。主实验使用 T = 512、每个情形 2,000 次独立重复、每次 1,999 次 stationary bootstrap；名义单侧水平为 5%，HAC 滞后为 5，期望块长为 16，根种子为 20261002。方法与参数在完整运行前固定，结果没有用于重新选择种子、带宽或块长。

下面的百分比为拒绝次数除以模拟次数；区间是 95% **点态 Monte Carlo Wilson 区间**。它反映有限模拟次数的误差，不是策略收益参数区间，也不是跨情形的同时区间。

## 1. 时间依赖的影响

零均值高斯 AR(1) 的自相关为 0.8，只有一个候选时：

| 方法 | 误报率 | Monte Carlo 区间 |
| --- | ---: | ---: |
| IID t | 29.65% | 27.69%–31.69% |
| HAC z | 14.25% | 12.79%–15.85% |
| 单列 stationary bootstrap | 9.70% | 8.48%–11.08% |

方向与长程方差推导一致：忽略正自相关会低估样本均值的不确定性。但“做了依赖调整”并不意味着实际误报率已经是 5%。该设置下默认 HAC 带宽和 Bootstrap 块长的有限样本偏差明显。增加 Bootstrap 次数只会更精确地估计当前重抽样分布，不能解决近似分布本身的偏差。

原始计数：[figure-1-dependence.csv](../results/full/figure-1-dependence.csv)。

## 2. 策略筛选的影响

在同一段历史上搜索 50 条相关的高斯 AR(1) 策略，所有真实均值均为零。自相关为 0.5，横截面创新相关参数为 0.35。统一选择最大 HAC 统计量对应的候选：

| 方法 | 误报率 | Monte Carlo 区间 |
| --- | ---: | ---: |
| 胜出者的 IID t | 89.70% | 88.29%–90.96% |
| 胜出者的 HAC z | 70.90% | 68.87%–72.85% |
| 全族 stationary-bootstrap max | 10.85% | 9.56%–12.29% |

HAC 的单列标准误处理时间依赖，不能直接处理挑选胜出者带来的分布变化。联合 Bootstrap 显著降低了该模拟中的误报比例，但 10.85% 与 5% 仍有明确差距；其 Monte Carlo 区间不包含 5%。本轮结果不支持把默认联合检验宣传为已获得 5% 有限样本误报控制。

这一发现不能简单归因于块长一个因素。固定原样本尺度、HAC 估计误差、重抽样对依赖的近似和最大统计量的尾部，都可能共同影响有限样本表现；本轮设计尚未分别识别这些来源。

原始计数：[figure-2-selection.csv](../results/full/figure-2-selection.csv)。

## 3. 过程与检出能力

20 条零均值候选的联合检验结果为：

| 过程 | 误报率 | Monte Carlo 区间 |
| --- | ---: | ---: |
| 高斯 AR(1) | 8.65% | 7.50%–9.96% |
| 重尾创新 AR(1) | 10.10% | 8.85%–11.50% |
| 重尾创新 GARCH(1,1) | 6.25% | 5.27%–7.40% |

在第一列植入四个理论长程标准误大小的均值信号时，三种过程的全族拒绝比例分别为 92.65%、92.60%、91.45%。这是**拒绝全族原假设的概率**，不是正确选中第一列的概率。

三个过程的实际误报率不同，所以不能仅凭这些功效数字宣称某种过程更容易检出，或重尾不会降低方法性能。严格的功效比较需要在独立零假设校准样本上匹配实际误报水平，再用独立备择样本评价。当前图记录的是同一名义水平下的原始结果。

原始计数：[零均值](../results/full/figure-3-size.csv)、[植入信号](../results/full/figure-3-power.csv)。

## 4. 块长敏感性

单独预设的敏感性实验使用 200 次重复、399 次重抽样、20 条高斯 AR(1) 候选，自相关为 0.5。块长 4、8、16、32 的误报比例分别为 16.0%、11.5%、10.0%、11.0%。这些比例的区间较宽，本轮不能据此确定最佳块长，更不能从中挑一项替换主实验结果。

原始计数：[block-length-sensitivity.csv](../results/full/block-length-sensitivity.csv)。

## 5. 下一轮应回答的问题

当前版本已经能复现错误、区分两种调整并检查联合检验的有限样本表现。校准问题仍未解决。后续扩展应另存事前协议，保留本轮基线，而不是覆盖这些结果：

1. 在高斯 AR 设置中加入已知协方差的参考检验，核对有限样本拒绝率的基准。
2. 分开研究样本长度、HAC 带宽、块长与 Bootstrap 内重估尺度的影响。
3. 在独立模拟样本上进行校准，并在另一批零假设与备择样本上评价泛化误报率和功效。

完成这些步骤之前，`audit_returns` 应用于研究、公式核对与敏感性探索，不能仅依据其默认 p 值作已校准的实务显著性判断。
