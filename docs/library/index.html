strategy-inference

用于时间序列的滚动评估、模型比较与在线不确定性。模型通过简单 callable 接入，预测起点、步长、损失与检验结果一起保留。

可以完成什么

环节已有功能输出
切分与预测扩展／滚动窗、gap、多步预测、三种基线origin × lead × model 预测
评估平方、绝对、pinball、中央区间 score逐步长损失摘要
模型比较固定基准与步长的共享 max bootstrap平均改善、调整 p 值、诊断
在线区间单步衰减步长 conformal 跟踪先发出区间，再反馈更新
统计推断HAC、stationary bootstrap、Gaussian AR 参数集合均值与同时决定

窄屏可横向滚动表格与代码。模型训练、数据频率和适用条件由具体任务确定；不自动填补或删掉缺失观测。

安装与一条完整流程

Python 3.10+。核心依赖 NumPy 与 SciPy；表格导出可选 pandas，绘图可选 Matplotlib。GitHub 安装包无需克隆仓库，尚未发布到 PyPI。

python -m pip install https://github.com/Studyer-Tang/strategy-inference/releases/download/v0.6.0/strategy_inference-0.6.0-py3-none-any.whl
import numpy as np
from strategy_inference import (
    backtest, naive_forecast, drift_forecast,
    evaluate_forecasts, compare_forecasts, adaptive_intervals,
)

y = np.random.default_rng(17).normal(size=512).cumsum()
result = backtest(
    y, {"naive": naive_forecast, "drift": drift_forecast},
    initial_train_size=128, window=128, horizon=1,
)
scores = evaluate_forecasts(result, loss="squared")
comparison = compare_forecasts(
    result, baseline="naive", n_resamples=999, seed=17,
)
intervals = adaptive_intervals(
    result.actuals[:, 0], result.forecasts[:, 0, 0], scale=1.,
)
print(scores.records())
print(comparison.records())
print(intervals.coverage)

例子是模拟 random walk，展示调用流程。平均损失与已实现覆盖不是有效性的独立验证，也不保证未来表现。完整模拟例子见 time_series.py。

方法条件直接写在接口里

滚动预测只传入本折历史，但 callback 的外部状态仍须避免未来资料。多步目标可重叠，比较接口按一个事先固定的步长检验，绝不把重叠步长展平为更多样本。

Bootstrap 模型比较依赖平稳、弱依赖及合适矩条件。在线区间基于 ICML 2024 的衰减步长跟踪器，只支持单步顺序反馈；其理想递推保证是历史平均覆盖，不是每个时点或多步路径的同时覆盖。空集与无界区间明确保存，binary64 运算没有舍入认证。

近期方法与下一阶段

后续重点是成熟标签队列、多步误差相关性、条件覆盖与序贯模型集合。ICML 2025 在线优化 conformal在条件分位数具有线性结构等条件下研究条件覆盖；AcMCP 的 2026 修订稿处理多步误差相关性及随步长增加的覆盖代价。这两项目前是路线图，未接入公共接口。

数据诊断、经典模型接入、panel、变点、序贯模型比较及跨步长联合推断的范围与验收要求见 路线图。已有算法的复现与工程组织不作为研究创新宣称。
