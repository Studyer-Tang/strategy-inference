# 共同时间参数的信息利用：冻结评价

本轮达到的目标是：在相同覆盖预算和 GLS 目标下，用固定多列的信息缩小共同参数集合，并量化功效变化。正式结果支持若干场景中的明确改善；仍不足以把方法定位成普遍有竞争力的实用筛选规则。

## 1. 设计、冻结与计算

计算源冻结于 `7f9073d18b14a329264c5508204231c72cc5262f`。协议为 [joint-uncertainty-protocol.json](../experiments/joint-uncertainty-protocol.json)，新正式种子分别为 20261120、20261121、20261122。开发阶段尝试的似然混合方案及块构造没有使用这些正式数据。

10 个零均值、8 个功效、4 个混合真假场景，每阶段每格 1,000 份独立噪声。功效阶段 δ=2、3、6 共用同一份噪声，共计 **22,000 份独立阶段噪声、38,000 个含位移的数据集、220,000 条方法记录**。四个 worker 只改变执行顺序；总计算约 707.8 秒。每种认证方法使用同一 `α=.05、β=.005` 与同一 GLS 临界值。

旧方法只使用预设第 0 列的余弦 F 集合。新单列使用三尺度 Wilks 集合；新联合固定使用前 min(K,8) 列。联合方法的 Wishart 比消去未知同期协方差，并不假设策略独立；选列协方差奇异时保守回退。已知参数的参照掌握真实 φ，不能作为未知参数下可实现的竞争方法。

数学推导、已有方法与数值证书范围见 [joint-uncertainty.md](joint-uncertainty.md)。计算环境的 editable 分发元数据仍记为 0.3.0；实际研究源由上述冻结提交和逐文件 SHA-256 明确标识，发布软件版本为 0.4.0。原始元数据保留，不回写版本字符串。

新增时间对比本身并不普遍改善功效。G3 新单列只有 0.2%，旧单列为 1.3%；G5 也为 0.1% 对 1.3%。主要增益来自共同参数的联合方向，而多尺度预算分摊与矩界在单列情况下可能更昂贵。

G3 相同临界值的已知参数参照仍有 54.9% 功效，联合方法只有 9.4%，留下 45.5 个百分点的配对成本。G5 相应为 59.7% 对 3.0%。有效覆盖与功效竞争力是不同结论。

## 3. 较强信号与剩余失败

δ=6 时，同一冻结数据给出：

| 组 | 已知参数、同临界值 | 旧单列 F | 新单列多尺度 | 新联合多尺度 |
|---|---:|---:|---:|---:|
| G2 | 100.0% [99.6, 100.0] | 10.7% [8.9, 12.8] | 25.5% [22.9, 28.3] | 99.2% [98.4, 99.6] |
| G3 | 99.9% [99.4, 100.0] | 12.2% [10.3, 14.4] | 1.5% [0.9, 2.5] | 88.0% [85.8, 89.9] |
| G4 | 99.5% [98.8, 99.8] | 5.9% [4.6, 7.5] | 1.0% [0.5, 1.8] | 74.1% [71.3, 76.7] |
| G5 | 100.0% [99.6, 100.0] | 6.5% [5.1, 8.2] | 0.5% [0.2, 1.2] | 53.9% [50.8, 57.0] |
| G6 | 100.0% [99.6, 100.0] | 0.1% [0.0, 0.6] | 0.0% [0.0, 0.4] | 0.0% [0.0, 0.4] |
| G9 | 100.0% [99.6, 100.0] | 13.0% [11.1, 15.2] | 2.0% [1.3, 3.1] | 90.7% [88.7, 92.3] |
| G10 | 99.9% [99.4, 100.0] | 13.2% [11.2, 15.4] | 1.0% [0.5, 1.8] | 0.0% [0.0, 0.4] |

G3 从 12.2% 提高到 88.0%，G4 从 5.9% 提高到 74.1%，说明共同参数的联合信息在较强信号下确实改变了可用性。G5 则仍为 53.9%，低于已知参数的 100.0%。

G6 只有一列且 φ=.99：新方法 δ=2、3、6 均无检出，旧方法也只有 1/1,000。不能把多列方法的收益推广到这一情形。G10 完全重复列使选定协方差奇异，新联合方法全部回退到 [0,1]；旧单列在 δ=6 有 13.2% 功效，联合方法为零，这是严格保守处理带来的真实损失。

## 4. 覆盖、边界与集合宽度

下面只列存在共同参数的零均值场景。宽度是区间并的总长度；空集合长度为零，不能把它自动视为成功。

| 组 | 联合参数覆盖 | 旧 / 新单列 / 联合平均宽度 | 旧 / 联合保留 φ=1 |
|---|---:|---:|---:|
| G1 | 99.9% [99.4, 100.0] | 0.6412 / 0.6066 / 0.1971 | 0.5% / 0.0% |
| G2 | 100.0% [99.6, 100.0] | 0.7640 / 0.6224 / 0.1986 | 0.5% / 0.0% |
| G3 | 100.0% [99.6, 100.0] | 0.1851 / 0.2129 / 0.0701 | 28.9% / 0.0% |
| G4 | 100.0% [99.6, 100.0] | 0.1837 / 0.2116 / 0.0703 | 28.9% / 0.0% |
| G5 | 99.7% [99.1, 99.9] | 0.0588 / 0.0995 / 0.0345 | 69.3% / 4.6% |
| G6 | 100.0% [99.6, 100.0] | 0.0830 / 0.1151 / 0.1151 | 99.6% / 99.9% |
| G7 | 100.0% [99.6, 100.0] | 0.1826 / 0.2108 / 0.0701 | 29.7% / 0.0% |
| G9 | 100.0% [99.6, 100.0] | 0.1812 / 0.2120 / 0.0701 | 27.5% / 0.0% |
| G10 | 100.0% [99.6, 100.0] | 0.1850 / 0.2115 / 1.0000 | 28.7% / 100.0% |

G3 平均宽度从 .1851 减少到 .0701，边界保留从 28.9% 到零；G5 从 .0588 减少到 .0345，边界保留从 69.3% 到 4.6%。这些是在有效模型内的信息改善，仍不是每个样本上集合包含关系或全模型功效排序的证明。

排除 φ=1 是拒绝的必要条件，不是充分条件。G5 即使多数路径排除了边界，δ=3 仍只有 3.0% 功效：剩余最不利参数检验依然很苛刻。单列多尺度在 G3 保留边界 91.0%，进一步说明时间改造和联合信息必须分开评价。

参数覆盖保证来自证明；模拟只报告这组有限实验的包含计数。最低联合零均值覆盖点估计为 G5 的 99.7%，其点态区间包含名义 99.5%；不由这些有限计数推导普遍保证。

模型内这 13 格的最高点估计为 0.4%，仍相当保守。混合场景仅计算零均值奇数列的任何误拒，不能把真实信号检出算作错误。

**G8 不满足共同 AR 模型。** 因子持久性 .98、特有持久性 .3。旧 F、新单列和新联合的全零均值误报分别为 0.3%、16.0%、7.5%；联合点态区间为 [6.03%,9.30%]，超过 5%。该格没有共同真实 φ，不能画或解释其“共同参数覆盖”。

G8 联合零均值阶段有 758/1,000 个空集合，功效阶段有 752/1,000 个空集合。δ=6 的联合检出率只有 24.8%，正是剩下 248 条非空路径全部检出后的平台。空集不拒绝使总体率下降，却没有令剩余路径获得模型外保证；宽度很小或大量空集合也不是参数准确性的证据。

在理想共同模型内，空集事件包含于参数覆盖失败，概率至多 β。它可作为模型冲突信号，但非空并不确认模型，G8 的非空路径仍表现失准。

## 6. 计算证据与可复核范围

三种认证方法共 114,000 次调用、涉及 3,252,000 个逐列决定；全部记录的拒绝认证预算未决数为零。这个数字说明本批结果中的功效下降主要不是拒绝证书预算耗尽，并不保证改变参数集合深度没有影响。联合集合末层未决叶片共 56,777 个，全部保留；这与拒绝证书预算耗尽是不同诊断。

审计核对 **220,000 条记录**的哈希、预设设计、掩码、参数区间与包含关系，并核对 1,116 项比例汇总、432 项配对结果和 114 项集合几何汇总。每格预定的三个独立噪声样本，含全部位移，完整重新生成：**114 个含位移数据集、342 套 F/Wilks/GLS 证书**。其余数值证书没有再次计算。

审计不是对历史文件哈希的单次检查，也不声称用另一套算法证明了全部未重算的数值决定。冻结协议、完整 CSV、determinant 多项式、精确根及计算诊断共同提供追溯依据。

另一份不导入研究实现的[概率界核验脚本](../scripts/verify_joint_bounds.py)，从 Beta 积分的有理数恒等式重新检查所存快照：678 个可用尺度的自由度、矩存在范围、共享预算、外向 dyadic 根和 Chernoff 不等式全部通过，另有 6 个不可用尺度按全域回退。该核验不重新证明所存行列式多项式，也不替代上述数据重生成；两份审计的范围分别记录。

## 7. 本轮定位与后续研究

本轮可发布为**共同参数信息更充分的保守研究基线**：它在若干预设模型内缩小集合并提高功效，给出同一模型下的覆盖与强 FWER 证明，也保留反例。不能称其对所有策略相关结构普遍更强，不能宣称新 Wilks 或投影推断原理，也不能将模型外失准省略。

下一步应优先量化三类成本：精确 Wilks 分位数相对当前矩界的保守差距；八列上限与连续行列式认证的计算代价；奇异支持空间的合法降维及观测舍入范围。任何新的默认选择都需要另立协议和独立种子，不能用本轮正式数据挑最优设置后重新作确认性宣称。
