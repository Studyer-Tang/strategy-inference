# 方差期望正确以后，筛选检验仍可能失准

机制诊断结果，2026-10-03。计算协议在提交 `769e5ff60a2f6e0705bdf630d7bd0ea59127695a` 冻结，正式随机种子为 `20261007`。这是 v0.2.0 之后的一项独立研究；原协议、报告和失败记录继续保留。

## 问题与结论

本轮追问的是：改善单列方差估计，是否已经足以校准策略筛选后的最大统计量？在最简单、总体参数可以精确计算的 Gaussian AR(1) 模型中，答案仍是否定的。

最能区分机制的参照，并不是某个拟合方法，而是**使用真实参数，使每列方差估计的期望精确等于有限样本真值**。在 `T=512, φ=0.9, K=100, ρ=0` 下，该参照的误报率仍为 **10.52%**，点态 95% Monte Carlo 区间为 **9.70%–11.40%**。这排除了“只要消除方差估计的平均偏差就能恢复 Gaussian 临界值”的解释。它不排除随机尺度的尾部波动、均值与尺度的依赖，以及按随机分母选择候选所带来的影响。

这些参照使用未知于实务的真实参数，目的在于辨认误差来源。这里还没有给出可以直接用于未知模型的联合检验，也没有把实验图当作新的有效性定理。

## 生成模型和比较对象

所有格点的真实均值均为零。候选列由一个共同 AR(1) 成分和彼此独立的个体 AR(1) 成分构造，时间自回归系数相同、边际方差为 1，列间同期相关为 `ρ`。第一期直接从平稳分布生成。`ρ` 在所有方法的临界值计算中均视为已知。

每种方法检验

\[
\max_{j\le K}\frac{\sqrt T\bar X_j}{\sqrt{\widehat v_j}}>q_{.95}(K,\rho),
\]

其中 `q` 是标准等相关 Gaussian 最大值的 95% 分位数，`v_T=T Var(平均值)`。只有使用真实 `v_T` 的参照具有与该临界值匹配的精确 Gaussian 尺度。其他统计量的 Gaussian 尾部值不能被当作已验证的 p 值。

| 记录名称 | 随机尺度 | 所用参数 |
| --- | --- | --- |
| `oracle` | 真实有限样本 `v_T` | 真实 `φ,ρ` |
| `bartlett` | 中心化 Bartlett HAC | 已知 `ρ`，不补尾 |
| `tail_known_lrv` | HAC × `Ω/M_ℓ` | 真实 `φ,ρ` |
| `tail_plugin_lrv` | HAC × `Ω(φ̂)/M_ℓ(φ̂)` | 样本拟合 `φ̂`，已知 `ρ` |
| `tail_known_finite` | HAC × `v_T/M_ℓ` | 真实 `φ,ρ` |
| `tail_plugin_finite` | HAC × `v_T(φ̂)/M_ℓ(φ̂)` | 样本拟合 `φ̂`，已知 `ρ` |
| `mean_unbiased_oracle` | HAC × `v_T/E(HAC)` | 真实 `φ,ρ` 和精确二次型期望 |

带宽预先固定为 `lags=floor(4(T/100)^(2/9))`，论文的 `ℓ=lags+1`。`φ̂` 是样本中心化后的 `γ̂₁/γ̂₀`，与 Liu–Chan Example 3.1 的拟合公式对应；它不是作者软件封装所调用的 `tseries::arma` 拟合。有限样本分子来自论文 Remark 3.2，不能称为本项目发明的修正。

## 三个可核对的现象

### 1. 总体补尾没有消除有限样本中心化偏差

在 `T=200, φ=0.99, ℓ=5` 下，Gaussian 二次型精确计算给出

\[
v_T=113.26399,\qquad M_\ell=4.92060,\qquad E\widehat\Omega=2.06223.
\]

真实参数有限目标补尾的期望比为

\[
\frac{E\{v_T\widehat\Omega/M_\ell\}}{v_T}
=\frac{E\widehat\Omega}{M_\ell}\approx0.4191.
\]

论文的总体核尺度 `M_ℓ` 不是中心化、有限长度 HAC 的精确期望。样本边缘权重与中心化项仍然存在。此时单候选误报率分别为：Bartlett **41.56%**，真实参数有限目标补尾 **17.10%**，拟合参数有限目标补尾 **25.42%**。这些数值不能与原论文的自动带宽、双侧 Table B.7 直接比较。

### 2. 消除边际期望偏差仍不足以校准尾部

以下均为 `T=512, φ=0.9, K=100`，每格 5000 轮；括号内为点态 95% Wilson 区间。

| 尺度 | `ρ=0` 误报率 | `ρ=0.35` 误报率 |
| --- | ---: | ---: |
| 真实有限样本方差 | 5.40%（4.81–6.06） | 5.12%（4.54–5.77） |
| Bartlett | 99.74%（99.56–99.85） | 76.28%（75.08–77.44） |
| 真实参数 LRV 补尾 | 11.78%（10.92–12.70） | 9.70%（8.91–10.55） |
| 拟合参数 LRV 补尾 | 24.42%（23.25–25.63） | 18.10%（17.06–19.19） |
| 真实参数有限目标补尾 | 12.90%（12.00–13.86） | 10.24%（9.43–11.11） |
| 拟合参数有限目标补尾 | 25.30%（24.11–26.52） | 18.60%（17.55–19.70） |
| 每列期望精确无偏参照 | 10.52%（9.70–11.40） | 8.88%（8.12–9.70） |

均值无偏参照在单候选 `T=200, φ=0.99` 下也有 **8.40%**（7.66–9.20）的误报率。因此，随机分母的问题并不依赖多候选才出现。多候选会进一步放大它，不能把全部失准归因于多重比较遗漏：这里所有方法已经使用对应 `K,ρ` 的 Gaussian 最大值临界值。

### 3. 被选列与平均列是不同的诊断对象

`T=512, φ=0.9, K=100` 下，均值无偏参照的所有列平均方差比在两种相关结构下分别为 **1.00015** 和 **0.99933**；按各自统计量胜出的列，其平均方差比却为 **0.87302** 和 **0.88970**。

这一对数字说明：总体上尺度期望正确，并不意味着按该随机尺度选出的候选仍拥有同样的尺度分布。第三张图把胜出候选的真实标准化均值与尺度比同时画出，蓝色曲线给出拒绝边界。这是机制证据，不是三个误差来源的可加分解；不能从这些均值直接读出各机制对误报的独立贡献。

在预设温和趋近单位根序列 `φ_T=1−T^(−1/2)` 中，`K=20,ρ=0.35` 的拟合有限目标补尾误报率随 `T=256,1024,2048` 为 **28.44%、17.96%、13.74%**。方向与渐近改善一致，但三个有限样本点既不能证实渐近定理，也不能据此宣布 `T=2048` 已校准。

## 与论文的关系

直接基线是 [Liu–Chan，Tail Postcoloring in Long-Run Variance Estimation of Time Series，JASA 2026](https://doi.org/10.1080/01621459.2026.2676715)，阅读版本为 [arXiv v1](https://arxiv.org/html/2605.15596v1)。我们复现固定带宽 AR(1) 的数学构造，并对中心化有限样本尺度、随机分母和多候选筛选作逐层诊断。没有复现作者完整的自动带宽及拟合流程。

作者 R 包的三个原始函数在独立的 R 4.6.0/WebR 环境运行，本项目 Python 实现与其 **48 个标量结果**交叉核验，最大相对误差 **2.19×10⁻¹³**。参照仅覆盖核尺度、给定参数的修正与基准 HAC，不代表整篇论文复现完成。作者 GPL 源码没有并入本项目。参见[运行来源](../results/research/verification/author-r-runtime.json)和[逐项对照](../results/research/verification/tail-reference-comparison.json)。

精确矩、固定样本强持久性反例及温和持久性的限定推导见[机制命题与证明](tail-mechanism.md)。[已知参数下的候选规模充分界](oracle-selection-bound.md)进一步连接持久性、带宽、候选数与共同相关，区分相关结构对阈值敏感度的影响。基本 Gaussian 二次型恒等式、事件夹逼、集中界和 Jensen 论证不包装为原创；最新论文没有直接给予我们未知相关矩阵、拟合尺度的增长候选数及随机临界值的保证。后续研究增量应围绕这些未解决的量展开，而不是改名已有补尾公式。

## 证据与复现

```bash
python -m pip install -e '.[figures,dev]'
python scripts/tail_diagnostics.py --profile full --output results/research/tail/reproduced
```

一条命令计算、保存逐轮压缩 CSV、校验哈希并生成 PNG/SVG/PDF 和 HTML。输出目录必须为空，以免覆盖已有记录。`quick` 使用另一种子，仅检查流程；本轮结果不使用其误报率。

原始日志保存随机地址、统计量、胜出列、尺度比和拒绝决定。全部 420000 个判决、84 个汇总和 72 个配对比较已独立重算；计算源哈希对应冻结提交，原始输出哈希全部一致。[独立审计记录](../results/research/verification/full-audit.json)可核对范围。

区间只反映 Monte Carlo 误差，为点态区间。配对风险差、区间及 McNemar 值是描述性输出，未作多重比较调整。本轮是机制研究，没有沿用 v0.2.0 的 19 场景验收门槛，也没有据观察结果调参后重新报告为独立评价。

## 下一步的可检验问题

首先研究估计相关矩阵与随机尺度共同进入临界值时的误差，随后再讨论候选数增长。候选规则必须先由推导或独立开发数据确定，再用未见过的新种子评价；同时报告实际尺寸与相同尺寸下的检出能力。当前补尾模块仍是研究参照，没有接入公共 `audit_returns` 默认流程。
